# Tracking project

A single-page web application for experimenting with computer vision tracking algorithms.

## Application requirements

- Make this project a simple single-page web application.
- Use vanilla javascript.

## Workflow requirements

- This is a solo project. Work directly on the "main" branch; don't create feature branches or PRs.
- Pull the latest "main" before starting new work.
- After a batch of work, commit it to "main" and push.
- The main branch is deployed to a github pages site (https://feifey.github.io/qrcode-tracking/). Note this URL after each push.
